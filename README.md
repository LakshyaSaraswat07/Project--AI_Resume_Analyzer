# 🚀 AI Resume Analyzer & ATS Checker

A smart web application that analyzes resumes against job descriptions, calculates ATS scores, identifies missing keywords, performs skill gap analysis, and provides improvement suggestions to enhance resume quality.

---

## 📌 Project Overview

This project helps job seekers evaluate how well their resumes match a specific job description.

The application extracts text from uploaded PDF resumes, compares it with the job description, calculates an ATS Match Score, identifies missing keywords, rates different resume sections, and provides actionable recommendations for improvement.

---

## ✨ Features

- 📄 Upload Resume in PDF format
- 🤖 ATS Score Calculation

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/LakshyaSaraswat07/Project--AI_Resume_Analyzer.git
```

### Move into Project Folder

```bash
cd Project--AI_Resume_Analyzer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

### Open Browser

```text
http://127.0.0.1:5000
```
